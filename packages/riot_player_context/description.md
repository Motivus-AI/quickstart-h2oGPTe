# riot-player-context

Local MCP tool for the Riot Support Agent. Simulated player APIs (no production PII).

## Tools

- `get_account_status(riot_id, player_id)`
- `get_ban_reason(account_id, player_id)`
- `get_ticket_history(player_id)`
- `get_purchase_history(player_id)`

Upload this folder as a ZIP to **Agents > Tools > Local MCP** in Enterprise h2oGPTe.
The MCP server name must be `riot-player-context`.
