# VAN 57 — Error al iniciar Valorant

**Categoría:** Errores de Vanguard  
**Códigos relacionados:** VAN 57

VAN 57 indica que Vanguard no pudo verificar la integridad del cliente al iniciar Valorant.

## Pasos recomendados (agente humano)

1. Pedir al jugador un reinicio completo de Windows (no solo del cliente).
2. Confirmar que Secure Boot y TPM 2.0 están habilitados si el sistema lo requiere.
3. Reparar Vanguard desde el instalador de Riot.
4. Si persiste tras reinstalación limpia, **escalar** con logs de `vgkbootstatus`.

## Cuándo cerrar

El ticket se puede cerrar si el jugador confirma que el juego inicia después de reparar Vanguard.

## Cuándo escalar

Escalar si VAN 57 continúa después de reinstalación, o si hay hardware no soportado.
