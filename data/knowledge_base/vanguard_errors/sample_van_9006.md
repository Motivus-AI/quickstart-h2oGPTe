# VAN 9006 / VAN 128 — Vanguard bloqueó el arranque

**Categoría:** Errores de Vanguard  
**Códigos relacionados:** VAN 9006, VAN 128, VAN 2266

Estos códigos suelen indicar un conflicto con software de terceros, overclock inestable o un driver de kernel no firmado.

## Pasos recomendados

1. Pedir lista de overlays (Discord overlay, GeForce Experience, RGB vendors).
2. Arranque limpio de Windows y probar Valorant.
3. Actualizar chipset y GPU.
4. Deshabilitar overclock de RAM/CPU.

Escalar si el error aparece en hardware de laboratorio o tras un baneo reciente (posible correlación con integridad).
